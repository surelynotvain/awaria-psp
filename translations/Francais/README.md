# Français (French)

Translation by **Supershadow30**: [[FR] Traduction FR Intégrale](https://steamcommunity.com/sharedfiles/filedetails/?id=3394046869) (Steam guide), originally made for the PC version of Awaria.

The `.json` files are the translator's original text files. `psp.json` (PSP dash prompt, credits role, Settings > Language) and `static.json` (texts placed in the game's scenes) were added for the PSP port in the same style.

Ready-made `LANG.PAK`: `LANG-Francais.PAK` on the [Releases page](https://github.com/surelynotvain/awaria-psp/releases). Rename it to `LANG.PAK` and copy it next to `EBOOT.PBP`.

Are you the translator and want something changed or removed? Open an issue.
